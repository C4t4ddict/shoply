# Shoply

여러 쇼핑몰에서 발견한 상품을 쇼핑 플레이리스트별로 모으고, 수량을 반영한 플레이리스트 합계를 확인하는 로컬 전용 Chrome 확장 프로그램입니다.

- AI 및 유료 API 없음
- 별도 서버와 회원가입 없음
- 상품 데이터는 사용자의 `chrome.storage.local`에만 저장
- 에이블리, 무신사, 쿠팡, 네이버 쇼핑 및 일반 상품 상세 페이지 지원
- Chrome 133 이상 지원

## Chrome에서 실행하기

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 프로젝트 폴더를 선택합니다.
5. 상품 상세 페이지에서 Shoply 아이콘을 누릅니다.

현재 페이지를 다시 읽으려면 패널 오른쪽 위의 새로고침 버튼을 누릅니다. 페이지에서 우클릭한 뒤 **현재 상품을 Shoply에 추가**를 선택할 수도 있습니다.

에이블리, 무신사, 쿠팡, 네이버 쇼핑은 별도 절차 없이 읽습니다. 그 외 사이트에서는 처음 **현재 페이지 읽기**를 실행할 때 Chrome 툴바에 표시되는 Shoply 사이트 접근 요청을 허용해주세요. 권한은 사용자가 허용한 사이트에만 유지됩니다.

## 상품 추출 방식

추출기는 다음 신호를 조합해 현재 상품을 찾습니다.

1. `Product`/`Offer` JSON-LD 구조화 데이터
2. `itemprop="price"`, Open Graph 상품 메타데이터
3. 쇼핑몰별 제목·가격 선택자
4. 상품명 및 구매 버튼과의 거리, 판매가 라벨 등 DOM 점수
5. 배송비, 쿠폰, 할부금, 취소선 가격, 추천 상품 영역 감점

자동 인식 결과는 저장 전에 수정할 수 있습니다. 쇼핑몰 화면 구조는 수시로 바뀔 수 있으므로, 패널에 표시된 현재 판매가를 확인하는 흐름을 제품의 기본 안전장치로 사용합니다.

## 플레이리스트 데이터와 합계

상품은 쇼핑몰과 관계없이 같은 플레이리스트에 묶입니다. 내부 데이터 호환성을 위해 식별자 이름은 `categoryId`를 유지합니다. 플레이리스트 합계는 다음 식으로 매번 다시 계산됩니다.

```text
플레이리스트 합계 = Σ(상품 현재 가격 × 수량)
```

동일 URL과 옵션의 상품을 같은 플레이리스트에 다시 담으면 새 항목 대신 수량이 증가합니다. 상품의 수량 또는 플레이리스트를 변경하면 저장소 변경 이벤트를 받아 화면과 합계를 즉시 다시 렌더링합니다.

쇼핑 카테고리 영역은 헤더의 화살표 버튼으로 접고 펼칠 수 있으며, 접힘 상태는 브라우저에 저장되어 사이드패널을 다시 열어도 유지됩니다.

카테고리 탭은 드래그해서 원하는 순서로 배치할 수 있습니다. 키보드에서는 탭에 초점을 둔 뒤 `Alt + ←/→`를 사용합니다. 변경된 순서는 브라우저에 저장됩니다.

현재 MVP의 합계 기준 통화는 KRW이며 배송비와 쿠폰은 포함하지 않습니다.

## 권한

- `activeTab`: 사용자가 Shoply를 실행한 현재 상품 페이지 읽기
- `scripting`: 로컬 추출기 실행
- `sidePanel`: 페이지 옆에 Shoply 컬렉션 표시
- `storage`: 상품과 플레이리스트를 브라우저에 저장
- `contextMenus`: 우클릭 상품 추가 메뉴 제공
- 지원 쇼핑몰 호스트 권한: 주요 쇼핑몰에서 페이지 이동 후에도 안정적으로 상품 읽기
- 선택적 호스트 권한: 그 외 사이트를 사용자가 허용한 경우에만 읽기

모든 사이트에 대한 상시 접근 권한은 요청하지 않습니다.
